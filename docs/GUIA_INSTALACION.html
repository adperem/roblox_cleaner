Cada paso depende del anterior — síguelos en orden la primera vez.

• Antes de empezar

Necesitas tres cosas instaladas. Nada de esto se descarga desde esta guía.

  • Una cuenta de Roblox (para abrir Studio).
  • Roblox Studio instalado.
  • git instalado y funcionando en tu terminal.
El PR #2 se cerró sin fusionarse a main. No afecta a esta guía: vas a trabajar directamente sobre la rama claude/roblox-pressure-wash-game-xebj53, que tiene todo el código. Si quieres que reabra el PR o que fusione a main antes de que sigas, dímelo.

0 Clona el repo y cambia a la rama del juego

El código de las 4 fases vive en una rama aparte, no en main.

terminal
git clone https://github.com/adperem/roblox_cleaner.git
cd roblox_cleaner
git checkout claude/roblox-pressure-wash-game-xebj53

1 Instala Rojo

El proyecto no se edita dentro de Studio — Rojo sincroniza lo que hay en src/ hacia un lugar de Studio abierto. Necesitas dos piezas: el plugin de Studio y algo que sirva los archivos.

Plugin de Studio (obligatorio)

  • Instálalo desde su página en el Creator Store.

Servidor Rojo (elige uno)

  • Extensión de VS Code Rojo (de evaera), o
  • CLI: cargo install rojo / aftman install

2 Abre Studio y crea un lugar

Cualquier plantilla vale, incluida Baseplate vacía. Si el lugar no tiene ya un suelo y un SpawnLocation, el propio juego crea uno mínimo al arrancar — no necesitas prepararlo tú.

3 Activa el guardado (opcional pero recomendado)

Game Settings → Security → "Enable Studio Access to API Services".

Sin esto el juego funciona igual de principio a fin — solo que ProfileStore avisa por consola y no persiste dinero, mascotas ni progreso entre partidas de prueba.

4 Sincroniza el proyecto

Desde la carpeta del repo:

terminal
rojo serve

O, si usas VS Code, la paleta de comandos → Rojo: Start Server.

5 Conecta el plugin

En Studio, pestaña Plugins → icono de Rojo → Connect. Verás aparecer ReplicatedStorage.Shared, ServerScriptService y el resto de carpetas del repo dentro del árbol de Studio.

6 Dale a Play

Apareces en el Barrio con la mira fija en el centro de la pantalla: gira la cámara para apuntar y mantén pulsado 💦 (o clic izquierdo en PC) para disparar agua a presión.

El botón ☰ (abajo a la izquierda) abre el menú con nueve pestañas:

🛠️ boquillas 🗺️ mapa 🎯 misiones 🐾 mascotas 💎 gamepasses 🏆 certificación 🎫 pase de temporada 🎁 códigos 🤝 comercio

+ Probar con varios jugadores

Los contratos VIP, la Mega Suciedad y el comercio de mascotas necesitan más de un jugador en el servidor para verse de verdad.

Pestaña Test → menú desplegable junto a Play → Play Here → elige 2 o más jugadores. Studio abre varias ventanas del cliente contra el mismo servidor local.
Publicar el juego de verdad opcional

No hace falta para probarlo en Studio — solo si quieres que exista como experiencia pública en Roblox.

  1. En Studio: File → Publish to Roblox As... y elige nombre y visibilidad.
  2. En el Creator Dashboard: sube icono, capturas y descripción.
  3. Roblox pedirá una clasificación de edad antes de hacerlo público.
  4. Si vas a vender los gamepasses reales (Dinero x2, VIP, Pase de temporada), créalos en el dashboard del juego publicado y copia sus ProductId a src/shared/Config/Gamepasses.luau — hoy están todos en 0 como marcador de posición. Vuelve a publicar tras el cambio.
